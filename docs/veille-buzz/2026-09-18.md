**BUZZ a confirmé son adoption interne chez Block et sa croissance communautaire (33.6k stars GitHub, 4.4x depuis juillet). Mobile RC et features critiques en cours. Écosystème Nostr consolidé, hype confirmé, substance progressive.**

## État du produit

- Lancé le 21 juillet 2026 ; version actuelle montre progression régulière avec 33.6k stars GitHub (de 7.6k en juillet), 4.4k forks, 1.6k issues ouvertes, 2.1k PRs actives [GitHub block/buzz, 18/09/2026]

- Mobile clients en Release Candidate (0.16.0 RC2 et 0.15.0 RC2 expédiés) ; desktop app stable avec GIF search, mention fixes, présence retry, CPU optimizations [Releasebot BUZZ updates, 09/2026]

- Matrice de features : ✅ relay, channels, mobile clients, desktop app, workflows ; 🚧 approval gates, push notifications, CLI tools ; 💭 governance features en attente [GitHub block/buzz status matrix, 18/09/2026]

- Block utilise BUZZ en interne comme remplacement production Slack + GitHub (dogfooding Nostr stack en production) [Benzinga, 21/08/2026]

- CEO Jack Dorsey confirmé lors earnings appel Q2 2026 que Buzz "elevates core technologies" de Block à nouveau niveau ; "model-agnostic, decentralized, self-sovereign, open source" [PYMNTS.com, 08/2026]

- Pas de token, pas d'airdrop, pas d'économie crypto ; positionné pure open-source collaboration stack [Enterprise DNA, KuCoin, 07/2026]

- Apache 2.0 license, self-host possible (Docker, Rust 1.88+, Node 24+, pnpm requis) [Multiple sources, 07/2026]

## Bonnes pratiques de démarrage

- Mobile now usable (RC stage) ; desktop reste l'expérience la plus stable pour pilotes early-stage [Releasebot, 09/2026]

- Vérifier que workflows critiques ne bloquent pas sur approval gates ni push notifications (toujours 🚧 work-in-progress) [GitHub matrix, 18/09/2026]

- Équipes Slack/GitHub ≥ 50 personnes : anticiper friction sur absence features enterprise (search avancée, compliance tooling, ecosystem intégrations) vs Slack decade-mature [Coherence/Julian Goldie analysis, 09/2026]

- Intégration agent IA : cas d'usage confirmé (Hermes Agent instances droppables dans channels, "free AI employees" si OpenAI/Claude API already subscribed) [Enterprise DNA, 08/2026]

- Rel
ayer unique par workspace = absence redondance pair-à-pair ; clarifier RTO/RPO avec Block avant production migration [Original veille, 29/07/2026]

- Nostr identity model maintenant plus mature ; écosystème relay infrastructure solidifié depuis juillet [Multiple sources, 09/2026]

## Usages possibles pour l'AI_LAB

- Test agent orchestration multi-modèle (Claude, OpenAI, local models) dans workspace unique avec cryptographic audit trail complète ; identity tracking natif Nostr [PYMNTS, Decrypt, 07/2026]

- Remplacement Slack+GitHub pour équipe R&D décentralisée ou crypto-sympathique sans dépendre Salesforce (Slack) ou Microsoft (GitHub) [Enterprise DNA, TechCrunch, 07/2026]

- Exploration workflow automation pour LLM agent teams avec approval gates (sitôt 🚧 implémentées) ; git forge intégré + canaux dédiés par branche [Original veille, 29/07/2026]

- Benchmark decentralized identity + AI permissioning vs centralized solutions ; contribution open-source possible via GitHub [Enterprise DNA, 08/2026]

- NOT: Production workload avant v1.0, mobile shipping, approval gates complètes, enterprise admin/search/compliance tooling [Consensus sources, 07-09/2026]

## Signaux faibles / risques

- **Mobile RC ≠ shipped** : deux releases candidate (0.16.0 RC2, 0.15.0 RC2) suggèrent mobilisation finale, mais timeline v1.0 non communiquée ; historique Dorsey/Block = shipping rapide, mais équipe taille ?  [Releasebot, 09/2026]

- **Sécurité agents IA (général, pas BUZZ-spécifique)** : 92% security pros concerned about AI agent impact ; CVE-2025-53773 (GitHub Copilot RCE via prompt injection, CVSS 9.6) ; EchoLeak (M365 Copilot exfil) relevants pour BUZZ multi-agent channels ; only 7.2% org have formal accountability [Darktrace, Gravitee, Bessemer Venture Partners, 2026]

- **Approval gates + permissioning incomplete** : workflows described as "not exec complete" (juillet veille) ; September matrix shows 🚧 approval gates, qui bloque use-case governance-critical [GitHub matrix, original veille]

- **Nostr relay single-point-of-failure** : un relay par workspace = pas redondance pair-à-pair automatique ; outage relay = outage workspace (sauf self-host multi-relay, non documenté) [Original veille, 29/07/2026]

- **Slack incumbency + Microsoft/Salesforce resources** : Slack decade-mature, $27.7B acquisition 2021 (Salesforce), vast integration ecosystem ; Buzz weeks-old open-source, feature parity still gap [BigGo Finance, Coherence analysis, 09/2026]

- **GitHub platform risk** : BUZZ distribuée via GitHub (github.com/block/buzz) mais hostée Nostr ; GitHub universe dominé Microsoft (copilot, Copilot X, Codespaces) ; regulatory risk Dorsey/Block x crypto x Nostr political [Multiple sources, 07-09/2026]

- **Community momentum vs. substance** : 33.6k stars strong signal, mais adoption enterprise entreprenant ? Traction stories sparse ; "hype cycle" vs "sustained growth" unclear [Enterprise DNA, TechCrunch, 09/2026]

**RECOMMANDATION :** BUZZ maintenant viable pour pilote équipe R&D mixte humain/agent IA en Q4 2026 (mobile RC → shipped expected sooner than v1) ; tester agent permissioning + audit trail (USP cryptographic). Surveiller shipping approval gates (débloque workflows production). Ne pas recommander production migration Slack avant v1.0 complet + enterprise features. Hype cycle entrée phase "substance" — Watch pour signal. Nostr écosystème consolidé, Block dogfooding crédible, crypto sentiment moindre risque (no token).
