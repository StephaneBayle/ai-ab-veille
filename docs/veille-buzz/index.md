# Veille Buzz — Monitoring BUZZ (buzz.xyz)

Suivi hebdomadaire de **BUZZ**, la plateforme de groupchat open-source lancée par Jack Dorsey / Block le 21 juillet 2026. Concurrent de Slack + GitHub, construit sur le protocole Nostr, licence Apache 2.0.

## Dernières entrées

- **[28/08/2026](./2026-08-28.md)** — Semaine 5-6 post-lancement : adoption fragile malgré traction communautaire, défis de maturité persist, Nostr protocol adoption niche, opportunité AI multi-agent réelle mais pas substitut Slack court-terme.

- **[29/07/2026](./2026-07-29.md)** — Semaine 1 post-lancement : produit viable mais incomplet, intérêt communautaire fort (7,600 stars GitHub en 3 jours), risques sécurité agent non résolus, freins UX significatifs.
