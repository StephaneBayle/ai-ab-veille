**Mois 2 post-lancement BUZZ : mobile shipping + refinements agent, mais Slack/Teams accélèrent leurs features AI natives ; adoption corporative resta limitée (pas d'hosting managed), substance à surveiller avant migration.**

## État du produit

- Desktop releases steady (v0.5.18-v0.5.20 en août) : ajout KLIPY GIF search, persistent agent addressing, workflow editor, image navigation multi-thread, amélioration UI/UX agent provenance [GitHub releases, 21-26/08/2026]

- Apps mobiles iOS et Android livrées (v0.8.0, lancé début août) : Apple App Store, Google Play ; setup QR-code fast (~5 sec) ; bug: messages d'agents non-visibles sur Android jusqu'à force quit [Block Engineering Blog, App Store, 03/08/2026]

- Kubernetes deployment path pour remote agents (v0.5.4) + security updates documentés ; dogfooding Block en production interne sur stack Nostr [X/ThomPete, 03/08/2026]

- Git forge avec Smart HTTP standard (branches=canaux) functional ; AI agents reviennent code, exécutent workflows, coordonnent revues code [Vers AI, 22/07/2026]

- Présenté comme "model-agnostic, decentralized, self-sovereign, open source" ; Apache 2.0 ; self-host mandatory (pas d'option managed encore) [TechCrunch, 21/07/2026]

- Repos GitHub github.com/block/buzz actif (pull requests réguliers, issues board) ; stack Rust+Postgres+Redis+MinIO [GitHub, ongoing]

## Bonnes pratiques de démarrage

- Tester mobile EN PRIORITÉ (apps live, setup rapide, UX allégée cf. desktop) mais vérifier Android agent display bug avant déploiement [App Store/Play logs, 03/08/2026]

- Self-host sur Kubernetes si agents critiques et faible latence requis ; Docker Compose classique sinon [GitHub releases, 21/08/2026]

- Attendre v1.0 et approval gates workflow (toujours en progress) avant migration code reviews/CI automatisées [GitHub PR status, ongoing]

- Formation Nostr keypair identity mandatory pour ops/admins ; un agent = une keypair + signature du propriétaire [Previous veille, 29/07/2026]

- Pilot petit équipe (5-20) en parallèle Slack+GitHub 2-3 semaines ; déployer workflow non-critique d'abord (chat pur, pas code) [TechCrunch best practice, 21/07/2026]

- Vérifier que relay infrastructure locale stable avant integration ; pas de relay redundancy multi-workspace today [Nostr dev docs, implicit]

## Usages possibles pour l'AI_LAB

- Veille techno + prototyping agent dans channel partagé ; cryptographic signature = audit trail pour agent experiments [GitHub issues, code integration, 21-30/07/2026]

- Slack replacement pour équipes R&D crypto/Nostr-sympathies ou labs décentralisés ; migration progressive doc + chat d'abord [Block deployment, ongoing]

- Testing ACP (Agent Client Protocol) pré-integré Claude + Goose multi-agent coordination en channel [GitHub block/buzz, xCloud sources, Jul 2026]

- NOT avant v1.0 : approval gates, push notifications, workflow execution gates toujours en chantier (pas d'exec complète) [GitHub releases, août 2026]

- NOT: HR/financial workflows ni stockage sensible data (Nostr event log immutable, audit trail public par design) [Previous veille concern, security implicit]

## Signaux faibles / risques

- **Momentum AI concurrent accelerated** : Slack lancé "Add to Slack" (AI agents Claude/Devin/Copilot/Vercel avec enterprise permissions, one-click deploy) ; Microsoft pours billions Copilot Teams integration, Slack Code live pour supported models [VentureBeat, Slackbot updates, 2026]

- **Market incumbent resilience** : Slack = ~80% Fortune 100 adoption, 13% enterprise messaging ; Microsoft Teams ~37% market share, 320M MAU 2026 ; Dorsey/Block déjà faced durability vs Uber et Twitter (timing, regulation) [TechCrunch, Multiple, Jul 2026]

- **Mobile ship retard résolu, mais UX bugs remain** : Android agent message display fix toujours pending ; iOS setup smooth mais adoption app-first vs web (contrary to Slack early strategy) [App reviews, 03/08/2026]

- **Relay infrastructure / scalability question open** : "no peer-to-peer event exchange, gossip layer, or replication between relays" — each workspace bound single relay (HN discussion noted contradiction vs "decentralized" pitch) [Hacker News, 21/07/2026]

- **No managed hosting = DevOps friction** : Self-host mandatory ; small teams discouraged (no Vercel-style "git push deploy") ; Block managed hosting rumored Q4 2026 but not shipped [Block blog silence, inference]

- **AI security / data leakage unchanged from veille 1** : agent reads full channel history, no explicit data-boundary controls ; Slack employee flagged on HN, Block non-responsive ; sensitive IP risk if agent compromised [Previous veille, HN thread, 21/07/2026]

- **Early adopter pool exhausted** : GitHub 7,600 stars (22/07) → growth stalled (no new metrics visible as of early Sept) ; hype phase may pass before enterprise pilots land [Repo watch, no updates cited]

**RECOMMANDATION :** Buzz semaine 6-8 post-lancement toujours viable pour veille agent-native workspace + Nostr patterns, mais RISQUE ADOPTABILITÉ CORPORATIVE monte (Slack/Teams native AI closing gap, managed hosting delay). Délai de migration: Q4 2026 minimum (v1.0, mobile stabilisation, workflows complets), Q1 2027 realistic pour équipes non-crypto. Hype fatigue prévisible si adoption corporative stagne dans les 2 mois. Surveiller: release frequency, bug triage mobile, Block managed hosting ship date, relay ecosystem health.
