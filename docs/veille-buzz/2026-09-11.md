**Buzz progression stable en v0.5 : focus sur UX/agent discovery, pas d'évolution majeure du produit-core depuis juillet. Adoption précoce timide en dehors de Block interne. Mobile et workflows toujours bloquants pour production.**

## État du produit

- Version 0.5.23 sortie 5 septembre 2026 ; série 0.5.x livrée depuis 18 août (v0.5.17 à v0.5.23 en 3 semaines) [GitHub releases, 05/09/2026]

- Améliorations ergonomie : indicateurs non-lus, unread activity sidebar, mentions persistantes copy/paste, persistance vitesse vidéo, agent availability indicators, Projects nav refinements [GitHub releases, 18/08–05/09/2026]

- Performance fixes : élimination CPU burn mounted-view (v0.5.17), storage optimization (v0.5.14), channel timeline preservation ; Rust h2 dependency security bump inclus [GitHub releases, 18/08–05/09/2026]

- Agent discovery amélioré : derive agent availability from relay presence (v0.5.22), remote agent mention authorization fixes, ACP handling renforcé [GitHub releases, 04/09/2026]

- Roadmap bloquée : mobile clients toujours en dev ("not shipped"), workflow approval gates incomplets, pas de fonctionnalité "killer" nouvelle documentée depuis juillet [TechCrunch, 21/07/2026 + sources août]

- Adoption GitHub : ~21.9K stars d'ici 4 août 2026 (vs 7.6K en 3 jours post-lancement, 21/07/2026) ; croissance stabilisée depuis lors [PYMNTS.com, 22/07/2026 + GitHub stars, 04/08/2026]

- Block self-hosting en production interne pour Slack+GitHub replacement (dogfooding) [TFTC, 22/07/2026]

## Bonnes pratiques de démarrage

- Version 0.5.x suffisamment mûre pour pilot interne (équipes R&D) mais NOT prod team-wide ; agent identity model stable, Nostr keypairs assignées, relay auth NIP-42 conforme [GitHub security.md + releases, 09/2026]

- Desktop app (macOS/Windows/Linux) seule option ; non considérer mobile pour workflow 2026, attendre v1.0 + clients mobiles livrés [GitHub releases, 05/09/2026]

- Security posture : Cargo audit (CI), #![deny(unsafe_code)] enforced, no unsafe Rust, NIP-42 authentication gate relay ; signaler vulns à buzz@block.xyz [SECURITY.md, GitHub]

- Nostr keypair self-custody toujours sans recovery ; spam low-barrier-to-account-creation = drift channel signal/noise ; moderation tooling clarification needed [GitHub issues, 09/2026]

- Self-host vs managed : relire tarification managed hosting Block.xyz (gratuit = licence, pas hosting tier) ; clarification pricing model attendue avant scale-up [Decrypt, 21/07/2026]

## Usages possibles pour l'AI_LAB

- Agent orchestration testbed : Buzz = cryptographically-signed audit trail pour multi-agent workflows (Claude + autres) ; chaque action signée, replay-auditable [Techstrong.ai, 22/07/2026]

- Nostr identity pattern lab : experimental decentralized identity (self-sovereign) baseline pour future auth stacks ; no need to commit prod data [explainx.ai, 2026]

- Internal chat + git hybrid : self-host Buzz pour équipe R&D séparant Slack-like collab de GitHub ; open-source baseline vs GitHub propriétaire [Block official, 21/07/2026]

- Model-agnostic agent testing : Buzz invite owned agents from standalone forums, agent addressing persistence (v0.5.19) = Claude/competitor agent side-by-side testing [GitHub releases, 25/08/2026]

- NOT prod migration 2026 : mobile absent, workflows incomplete, no Slack/GitHub feature parity, single relay per workspace (no P2P between orgs) [Multiple, 21/07–09/2026]

## Signaux faibles / risques

- **UX completeness plateau** : 3 semaines rapid fixes (v0.5.17→v0.5.23) suggest feature frenzy over ; no major UX announce depuis 18 août, patch-driven development dominates [GitHub releases, 05/09/2026]

- **Mobile ablation risk** : mobile clients still labeled "in progress" as of 05/09 ; if deprioritized, team-of-humans-and-agents narrative collapses (mobile = 60% workspace use, industry norm) [GitHub issues, 09/2026]

- **Relay centralization unresolved** : current arch = single relay per workspace + NIP-42 auth gate ; no peer-to-peer event exchange, gossip layer, or replication between relays documented (HN critique July) ; "decentralized" claim technically false [HN threads, 21/07/2026]

- **Data leakage between agents unaddressed** : Slack employee flag (July HN) re. agents in shared channel reading full history ; no documented agent sandbox, data minimization, or channel-scoped permissions [HN threads, 21/07/2026]

- **Crypto/Nostr skepticism in mainstream** : HR departments, DSIs still view Nostr/Bitcoin signaling as red flag (Block = crypto-aligned philosophy) ; adoption outside crypto/Web3 community thin [LinkedIn, job boards, 08–09/2026]

- **Incumbent defensive response predictable** : Microsoft (Teams + GitHub Copilot) and Salesforce (Slack + Einstein AI) shipping agent-into-chat faster, enterprise support/SLAs unmatched by Block [PYMNTS.com, 22/07/2026]

- **Governance & moderation vacuum** : single relay = single point-of-control for workspace data ; no documented org admin controls, audit dashboards, or channel governance policies (GitHub issues backlog unprioritized) [GitHub issues, 09/2026]

**RECOMMANDATION :** Buzz stabilise UX/performance (v0.5 series) mais pas de momentum produit neuf depuis juillet. Tester agent orchestration + Nostr identity patterns en R&D pilot (self-host), mais attendre v1.0 + mobile livré avant équipe production. Surveiller si mobile déprioritisé (signal d'abandon) et relay P2P roadmap (décentralisation credibilité). Adoption réelle en dehors Block interne : thin.
