**Dix jours post-lancement : adoption early-adopter stable, self-hosting devient critère de sélection, Claude Code + Codex adoptés en production pilote, risques Nostr + architecture monorelay confirmés.**

## État du produit

- Plateforme v0.4–v0.5, 7,600+ stars GitHub dès le 22/07, usage mesuré montrant adoption stable (pas de crash ou désengagement viral) [Hacker News trends, 22–29/07/2026]

- Desktop app fonctionnelle macOS/Windows/Linux ; relay Rust + stack backing (PostgreSQL + Redis + MinIO) open source et déployable via Railway/Docker, coût ~$15–30/mois self-hosted [Railway, BitDoze, 31/07/2026]

- Trois runtimes d'agent certifiés : Claude Code, OpenAI Codex, Block Goose via protocole ACP (Agent Client Protocol) ; agents reçoivent keypair Nostr propre + signature secondaire du propriétaire humain [explainx.ai, 25/07/2026]

- Intégration Git Smart HTTP standard ; branches créent canaux dédiés, revues et CI comments côte-à-côte discussion team [Block docs, 21/07/2026]

- Architecture monorelay par workspace : un seul relay "source de vérité", pas de réplication P2P en place ; tension documentée entre cohérence + décentralisation annoncée [Block GitHub, 31/07/2026]

- Chaîne d'onboarding desktop-first : mobile obligatoirement via desktop en première connexion ; issue #2735 flaggée comme blocker pour workflow headless-server [Block GitHub issue, 31/07/2026]

- Protocole Nostr utilisé pour identité + audit trail cryptographique ; every message/patch/approval = signed event dans relay event log [explainx.ai, 25/07/2026]

## Bonnes pratiques de démarrage

- **Stack backing requis** : PostgreSQL 17, Redis 7, MinIO (ou S3-compatible), DNS + TLS ; 2 vCPU min, 4 GB RAM recommended, 20–40 GB SSD [Railway, YapHaus, 31/07/2026]

- **Relay déploiement** : Dockerfile fourni, Docker Compose v2.24.4+ ; ports 3000 (relay WebSocket), 80/443 (Caddy) exposés publiquement [BitDoze, Railway, 31/07/2026]

- **Agent harness** : Claude Code integration ready via ACP ; Codex + Goose aussi supportés ; teams start small (1–2 agents pilote) avant multi-agent orchestration [Hacker News discussion, 22/07/2026]

- **Pilot recommandé** : équipes > 5 personnes doivent tester < 2 semaines avant décision self-host vs managed ; risques documentés de lockout + bugs early-stage [Block GitHub issues, 31/07/2026]

- **Nostr keypair management** : générer + sauvegarder localement ou via password manager ; perte de keypair = perte d'identité + accès (pas de recovery standard) [Quasa.io guide, 27/07/2026]

- **Pas de mobile first** : workflow dépendant de mobile = blocker ; utiliser desktop-only en pilot pour éviter surprises UX [Block GitHub issue #2735, 31/07/2026]

## Usages possibles pour l'AI_LAB

- **Agent orchestration lab** : déployer Claude Code + Codex dans canaux partagés pour étudier collaboration multi-agent, audit trail signé Nostr pour traçabilité décisions [Block docs, 25/07/2026]

- **Self-hosted Slack alt** : équipes tech sensibles données (privacy-first, crypto-aligned) trouvent alternative open source + self-hostable à Slack propriétaire [Hacker News, Decrypt, 21–22/07/2026]

- **Git + chat unification** : prototype rapide "code review dans chat" workflow ; branches = canaux, patches stockés côte-à-côte avec discussion [Block docs, 21/07/2026]

- **Nostr identity pattern research** : bac à sable pour explorer identité décentralisée appliquée equipe tech sans enjeu prod [TFTC, Block Nostr discussion, 22/07/2026]

- **Early adopter story** : doc interne "lessons learned self-hosting Buzz Q3 2026" pour future decentralized product decisions [Hostinger tutorial, YapHaus, 31/07/2026]

- **NOT production migration** : pas d'approval gates complètes, pas de mobile, pas de SSO/MFA ; Slack/GitHub stay primary 12+ mois [Block self-description, 21/07/2026]

## Signaux faibles / risques

- **Monorelay single-point-of-failure** : architecture par design = un relay par workspace ; pas de failover pair-à-pair documenté pour la v0 ; outage relay = outage complet workspace [Block GitHub, 31/07/2026]

- **Nostr infrastructure immature** : relay network stability lags enterprise message queues d'un ordre de magnitude (observability, reliability à prouver) ; Web-of-Trust reputation system design-only, non implémenté [TFTC, Decrypt, 22/07/2026]

- **Chaîne d'identité complexe** : agent keypair + human co-signature = surface d'attaque 2× ; perte keypair ou key leak agent = compromission directe audit trail ; pas de key rotation standard documentée [Decrypt, 21/07/2026]

- **Aucune données compliance** : pas de SOC2, pas de certifications, pas de garanties data location/retention, self-hosted = customer responsibility complète [Block docs, 21/07/2026]

- **Mobile onboarding paradoxe** : app mobile ne peut pas onboard seule (nécessite desktop d'abord) ; issue #2735 indique cette limitation n'est pas simple à fixer [Block GitHub issue, 31/07/2026]

- **Ecosystem vendor lock-in nouveau** : déplacer vers Buzz = créer dépendance Nostr + Block relay infra ; alternative Nostr UI quasi inexistante ; exit strategy floue [Hacker News thread, 22/07/2026]

- **Documentation traduit par hearsay** : Block label product "unfinished" + "early stage" ; articles tierces varient interprétation features ready vs future [Multiple sources, 25–30/07/2026]

- **Concurrence incumbent dormante** : Slack/Salesforce + GitHub/Microsoft n'ont pas réagi publiquement ; observateurs prédisent soit pricing dump, soit integration features ou defensive acquisitions [Decrypt, 21/07/2026]

- **Maturité 0.x** : "Hype strong, substance mitigée" — product roadmap : v1.0 ETA? Approval gates timeline? Mobile independent? Pas documenté publiquement [Block GitHub releases, 31/07/2026]

**RECOMMANDATION :** Continuer veille bi-hebdomadaire en août. Priorité : (1) self-hosting stability + deployment automation, (2) agent security spec public (keypair mgmt, access model), (3) mobile client maturity. Mettre pilot interne en pause jusqu'à August; relancer si v0.6+ + mobile beta land. Hype sustainability très dépendante de cadence release + early-adopter momentum.
