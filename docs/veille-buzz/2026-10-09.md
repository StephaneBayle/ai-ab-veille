**Aucune évolution majeure depuis le lancement (21/07/2026) ; développement itératif en cours (v0.5.0+), clients mobiles toujours en chantier, adoption stable mais sans signal de percée enterprise.**

## État du produit

- Aucune annonce de feature majeure en septembre–octobre 2026 ; couverture presse largement rétrospective (articles de synthèse juillet/août) [TechCrunch, Reworked, Hostinger, 08/2026–09/2026]

- Versions en circulation : v0.5.0+ (début octobre), v0.4.24 (mi-septembre), v0.3.26 (fin août). Changements principaux : invite links temporaires, filtres de recherche (`from:`, `in:`), fixes Windows (console, PATH, git credential helper), support NIP-34 git (patches, issues) [newreleases.io, dates approximatives]

- Desktop app Tauri 2 (React 19 frontend) livré macOS/Windows/Linux ; **clients mobiles iOS/Android annoncés mais toujours absent** — README officiel liste "mobile clients, push notifications, approval gates" comme inachevés [horadecodar.com.br, 08/2026]

- Hosted relay (buzz.xyz) reste libre et bêta ; auto-hébergement toujours l'option par défaut pour équipes sensibles données [Multiple, 07-08/2026]

- Git forge intégré via NIP-34 (branches → canaux, patches/CI/review stockés ensemble) ; workflows YAML locaux ou projet-level possibles [horadecodar.com.br, 08/2026]

- Pas de certifications entreprise publiées (SSO, SCIM, SOC 2, HIPAA, FedRAMP) ; documentation d'audit/compliance absente [Reworked, 08/2026]

## Bonnes pratiques de démarrage

- **Self-host recommandé.** Message non-E2E encrypté sur relay hébergé Block ; équipes sensibles sécurité doivent auto-héberger (nécessite Postgres, Redis, S3-compatible object storage) [claudemarket.ai, 09/2026 ; source secondaire mais cohérente]

- **Attendre clients mobiles.** Desktop requis pour productivité ; push notifications manquantes limite UX collaborative [newreleases.io, 08-09/2026 ; bloc: "en construction"]

- **Pairs agents sous supervision.** Buzz recommande agents avec audit trails séparés ; bonnes pratiques : une approval humaine avant merge/delete, mix harnesses (Claude Code + OpenAI Codex + Goose) pour diversifier capacités [claudemarket.ai, howdoiuseai.com, 07/2026]

- **ACP (Agent Client Protocol) compatible.** Agents Claude Code, OpenAI Codex, Block Goose supportés via harness wrapper (`claude-agent-acp`, `codex-acp`, etc.) ; endpoint OpenAI-compatible permet tiers agents [claudemarket.ai, 09/2026]

- **Petit POC d'abord.** Workflows YAML, issues NIP-34, git hosting en bêta ; aucune preuve d'équipes >20 en production [Reworked, 08/2026 ; matériel marketing quasi absent]

## Usages possibles pour l'AI_LAB

- **Expérimentation agent multi-modèle.** Testbed isolé pour orchestration Claude + OpenAI sans quitter interface unique ; audit trail cryptographique par agent (keypair Schnorr propre à chaque agent) [claudemarket.ai, 09/2026]

- **Workspace Nostr-native.** Exploration identité décentralisée (keypairs + permutations par canal) sans dépendre Slack; self-hosted pour lab interne R&D [horadecodar.com.br, 08/2026]

- **Git forge alternatif micro-projets.** NIP-34 git + webhook outbound (`call_webhook` YAML) permet CI externe ; branches-as-channels réduit context-switching doc/code [instagit.com, 08/2026 ; source secondaire sur architecture]

- **NOT pour workflows critiques.** Workflows "approval gates" toujours incomplets (pas de chemin d'exécution complet) ; git hosting v0.x pas production-ready [Reworked, 08/2026 ; WinBuzzer, 07/2026]

## Signaux faibles / risques

- **Pas d'audit sécurité publié.** Criticité relay centralisée (une relay = un workspace) non résolue indépendamment ; contrôle relay = contrôle communication/identité groupe [instagit.com, 08/2026 ; inféré des limites Nostr]

- **Relay mono-instance par workspace.** Pas de redondance pair-à-pair ni de replication relay cross-operator ; outage relay = outage workspace complet [Web search extensif, TechCrunch, 07/2026]

- **Adoption stagnante apparemment.** Stars GitHub (7,600 en 3 jours, juillet) : pas de chiffre mis à jour depuis août ; aucune annonce clients/partenaires majeurs [newreleases.io, Reworked, 08-09/2026]

- **Escalade produit-marché floue.** Positionnement "Slack + GitHub + AI" attire hype, mais cible (équipes <10 dev ? labs R&D ? crypto-native ?) non affirmé publiquement [Reworked, Vibe Coding, 08/2026]

- **Couverture presse décroît.** Juillet/août : >20 articles majeurs ; septembre/octobre : articles secondaires, aucune nouvelle couverture TechCrunch/Verge/Ars Technica [SearchResults agrégés, 09-10/2026]

- **Concurrence établie continue innovation.** Salesforce (Slack) : AI overhaul mars 2026 ; Microsoft (Teams/GitHub Copilot) : intégration agent continue [Reworked, 08/2026]

- **Risque abandonment court terme.** Block/Dorsey track record : acquires, pivots, ferme vite (voir Square→Block pivot, Twitter acquisition) ; Buzz peut rester low-priority si traction lente [Implicite, pattern historique, pas de source 2026 spécifique]

## Recommandation

À surveiller en Q4 2026 : **arrivée clients mobiles (priorité 1), signe d'adoption corporate (proof-of-concept public), durcissement sécurité relay.** Pour AI_LAB : **POC d'orchestration agent multi-modèle recommandé** en self-hosted, mais cycle production *non* envisageable avant v1.0 + mobile + SLA data.Hype apaisé ; substance mitigée.
