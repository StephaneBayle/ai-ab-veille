**Semaine 2 post-lancement BUZZ : consolidation produit, momentum GitHub stable, cas d'usage entreprise documentés, sécurité agent toujours TBD.**

## État du produit

- GitHub : 22.8k stars, 2.6k forks, activité de commit maintenue ; growth stabilisé après pic initial 7.6k-16k en 3 jours [GitHub block/buzz, 07/08/2026]

- En Developer Preview (not v1.0) ; commits réguliers sur main indiquent rythme de développement actif, releases non officielles listées [GitHub, 07/08/2026]

- Desktop app macOS/Windows/Linux opérationnelle ; clients mobiles toujours non livrés (inchangé vs 29/07) [Hostinger, 02/08/2026]

- Messages et média sur relays hébergés par Block ne sont pas chiffrés end-to-end ; prompts/contenu canal peuvent être traités par fournisseurs d'agents externes (Anthropic, OpenAI) [AGORA Intelligence, 04/08/2026]

- Modèle tarifaire toujours non précisé publiquement ; Apache 2.0 couvre licence logiciel, pas hébergement managed [Multiple, 07/08/2026]

- Block continue dogfooding interne sur Buzz en remplacement Slack/GitHub production [Originating from first entry, confirmé stable]

## Bonnes pratiques de démarrage

- Documenter avant déploiement agent : chaque agent lit l'historique canal complet ; noter quoi lit, quels services externes reçoivent prompts, où stocké fichiers, si logs contiennent credentials/données perso [AGORA Intelligence, 04/08/2026]

- Ne jamais paster clés API, données client privées, secrets production, ou données réglementées juste parce que l'interface ressemble à un chat team ordinaire [AGORA Intelligence, 04/08/2026]

- Self-host pour équipes haute sensibilité donnés ; modèle réseau (single relay par workspace vs redondance pair-à-pair) doit correspondre à RTO/RPO org [Enterprise DNA, 22/07/2026]

- Cas d'usage pour déploiements : automatiser checklist déploiement, merger to prod si checks passent ; exemple documenté : 14 sec cycle, 73% moins incident, 11.5h/sem saved coordination [Hostinger, 02/08/2026]

- Cas d'usage pour triage bug : recevoir rapports, catégoriser, prioriser, assigner dans même workspace où dev conversations [Hostinger, 02/08/2026]

- Vérifier résilience relay avant mission-critical workflows ; infrastructure Nostr jeune, Web-of-Trust reputation system design-phase (not live) [explainx.ai, 27/07/2026]

## Usages possibles pour l'AI_LAB

- Benchmark multi-agent orchestration (Claude, Codex, goose dans canaux partagés) ; testing ACP (Agent Client Protocol) déjà pré-intégré [Multiple, 07/08/2026]

- Lab interne : déploiement automation, code review agent, bug triage agent ; chaque agent avec keypair propre + audit trail cryptographique [Hostinger, 02/08/2026]

- Research R&D sur identité décentralisée agent (Nostr foundation) sans infrastructure blockchain/crypto business overhead [AGORA Intelligence, 04/08/2026]

- Training équipe sur permissions agent, audit trails, data sovereignty patterns avant application systèmes production [xCloud, 31/07/2026]

- NOT : données confidentielles, API keys, outputs productionalisés juste encore (v0.x, E2EE missing, specs sécurité non finalisées) [AGORA Intelligence, 04/08/2026]

## Signaux faibles / risques

- **Pas de crypto tokens** : bon signal (évite airdrop farming, scarcity mechanics) mais modèle économique Block long-terme flou [Multiple, 07/08/2026]

- **Traitement données par tiers** : relays Block non E2EE, Anthropic/OpenAI peuvent recevoir prompts ; compliance GDPR/HIPAA risqué sans vérification contrats [AGORA Intelligence, 04/08/2026]

- **Scepticisme technique HN persistant** : >200 commentaires questionnant si Nostr load-bearing ou "crypto theater" ; Slack employee flagged data-leakage multi-agent; pas de transparence Block réponse [Hacker News, 21-22/07/2026]

- **Timing UX** : mobile clients toujours undelivered ; push notifications pending ; approval gates workflows sans exécution complète [Hostinger, 02/08/2026]

- **Adoption entreprise lente** : aucun annonce client public post-lancement (vs ex. Figma/Notion early case studies) ; Block dogfooding ≠ third-party validation [Observation gap, 07/08/2026]

- **Market incumbent response** : Salesforce (Slack $27.7B 2021) et Microsoft (GitHub $7.5B 2018) peuvent matcher features rapidement ou baisser prix si volume menace ; historical pattern faster than startup [Multiple, 07/08/2026]

- **Documentation vs product delta** : Block label "unfinished" ; fork/self-host complexity TBD public ; adoption self-hosted vs managed asymétrique [Observation gap, 07/08/2026]

- **Absence de nouvelles majeures** : aucune release note officielle, aucune annonce d'intégrations LLM nouvelles, aucune évolution sécurité spec depuis 29/07 [GitHub, 07/08/2026]

**RECOMMANDATION :** Continuer veille ; momentum GitHub stable mais sans explosion suggère hype plateau. Priorité attendre v0.5+, spécification sécurité agent publique, et first enterprise case study documenté. Tester bac-à-sable multi-agent Q3 si temps. Pas prêt pour production critique avant v1.0 + E2EE + mobile.
