**État stable, adoption silencieuse : BUZZ demeure early-stage 3 mois post-lancement, aucune évolution majeure rapportée ; Google Play 4.7★ mais architecture centralisée compromet la proposition Nostr.**

## État du produit

- Lancé 21 juillet 2026 par Block (Jack Dorsey) ; toujours présenté comme groupchat humains + agents IA, protocole Nostr, Apache 2.0, zero news major en octobre [TechCrunch, 21/07/2026]

- Matériel inchangé : channels, threads, DMs, canvases, search, audit trail, Git integration précoce ; version ~0.4.x, pre-1.0, TechCrunch conseille toujours "don't move your team yet" [TechCrunch, 21/07/2026 ; WinBuzzer, 24/07/2026]

- Clients mobiles toujours en chantier ; desktop macOS/Windows/Linux sur GitHub (block/buzz, Apache 2.0) ; hosting managed sur buzz.xyz [Block engineering, 21/07/2026]

- Architecture centralisée malgré label Nostr : une seule relay par workspace = "single source of truth", aucun peer-to-peer relay replication décrit ; chaque keypair agent/humain cryptographiquement signé, mais nœud unique de défaillance [WinBuzzer, 24/07/2026]

- Google Play Android : 4.7/5 de 80 reviews en octobre ; utilisateurs rapportent bugs d'affichage (messages d'agents n'apparaissent que postredémarrage app), notifications natives manquantes, mais sentiment globalement optimiste [Google Play, octobre 2026]

- Product Hunt : aucune review formelle visible ; discussion d'early adopters enthousiaste, question sur révocation identité avec historique signé [Product Hunt, octobre 2026]

- Block engineering blog (Tyler Longwell) : "works really well for us" en interne ; reconnaît "raises lots of questions" [Block engineering, 21/07/2026]

## Bonnes pratiques de démarrage

- Self-host pour équipes sensibles au contrôle données (aucun relai redondant = confiance centralisée sur l'opérateur) ; clarifier tarification managed hosting avant onboarding [WinBuzzer, 24/07/2026]

- Déployer via desktop uniquement (mobile incomplet) ; pilote petit équipe recommandé, bugs connus d'onboarding managed (GitHub issues #2484, #2367 citées en juillet) [WinBuzzer, 24/07/2026]

- Comprendre identité Nostr avant agents : une keypair par agent (agent-spécifique), signature secondaire liant au propriétaire humain ; audit trail inclus [WinBuzzer, 24/07/2026 ; Block engineering, 21/07/2026]

- Vérifier que workflows critiques ne dépendent pas approval gates (portail DB, API, interface "in development" en juillet, pas d'exécution complète) [WinBuzzer, 24/07/2026]

- Évaluer alignement philosophique : écosystème Block fortement Bitcoin/Nostr/decentralization ; pas de neutralité politique assumée [Multiple sources, juillet 2026]

## Signaux faibles / risques

- Silence médiatique : zéro couverture majeure TechCrunch, Verge, Wired, Ars Technica, CoinDesk en septembre–octobre, contrairement aux jours post-lancement (juillet) ; hype cycle crashé ? [WebSearch extended, octobre 2026]

- Architecture "décentralisée" discutable : single relay par workspace ("single source of truth" selon code) revient à serveur centralisé rébranding Nostr ; pas de redondance relay inter-workspace décrite, pas de fusion de données cross-relay [WinBuzzer, 24/07/2026]

- Single point of failure : relay unique = panne totale accès workspace (données non perdues, mais locked until recovery) ; aucun failover, backup relay ou migration relay décrit [WinBuzzer, 24/07/2026]

- Block contexte : Block a licencié ~40% salariés (~4,000) mi-2026 citant "AI optimization" ; pas de source majeure, impact sur roadmap Buzz/support incertain [Secondary source, non vérifié]

- Adoption chiffres absents : zéro disclosure stars GitHub post-lancement, zéro DAU/MAU, zéro team count ; 80 Google Play reviews = signal très faible [Absence data, octobre 2026]

- Aucun signal Slack/Microsoft/Notion/Atlassian sur riposte produit ou M&A defensive ; sérénité concurrence ou ignorance stratégique ? [Absence signal, octobre 2026]

- Identité Nostr + approval gates en chantier = risque compliance/audit pour équipes réglementées (finance, santé) ; pas de documentation security model [WinBuzzer, 24/07/2026]

## Recommandation

**À surveiller.** BUZZ reste early-stage sans momentum visible post-juillet. La proposition décentralisée Nostr est affaiblie par relay centralisée par workspace — perte majeure de credibilité vis-à-vis Web3. Adoption silencieuse (pas de data) suggère either marginal enthusiasm ou early adopters discrets. Pour AI_LAB : tester en pilot contrôlé self-host seulement (relai interne), documenter limites centralisé, réserver jugement adoption jusqu'à roadmap 2027 (mobiles + approval gates + multi-relay).
